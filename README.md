# 아인이의 놀이터 🦖

7살 아인이를 위한 학습 게임 모음입니다. 브라우저만 있으면 어디서든 열립니다.

## 담겨 있는 것

```
index.html        놀이터 첫 화면 (게임 카드 목록)
games.json        게임 목록 데이터
games/            게임 파일들 (sudoku, maze, math, coding, puzzle, clock, memory, hangul, pattern, bull, spot, world-flags)
```

## 처음 한 번만 하는 설정

1. 깃허브에 새 저장소(repository)를 만듭니다. 이름은 예를 들어 `ain-playground`, 공개(Public)로 만듭니다.
2. 이 폴더의 파일 전부를 저장소에 올립니다.
3. 저장소의 Settings → Pages 로 들어가서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)` 로 지정하고 저장합니다.
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/ain-playground/` 주소가 열립니다. 이 주소를 아이 태블릿과 넷북 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

## 게임 추가 및 유지 관리

AI 어시스턴트(Antigravity)에게 게임 추가/수정을 요청하면 코드를 직접 리포지토리에 반영하고 배포합니다.

## 새 게임을 만들 때 지켜야 할 것

- HTML, CSS, JS를 한 파일에 담습니다.
- 세로 스크롤 없이 한 화면에 다 들어와야 합니다. 넷북(1366×768, 1024×600)이 기준입니다.
- 방향은 상·하·좌·우 절대 방향만 씁니다. 제자리 돌기 같은 상대 방향은 쓰지 않습니다.
- 「모두 지우기」 같은 초기화 버튼은 「출발하기」 같은 실행 버튼에서 멀리 떨어뜨립니다.
- 틀려도 게임이 끝나지 않게 합니다. 원래 자리로 돌려보내거나 힌트를 줍니다.
- 정답만 보여주지 말고 왜 그런지 과정을 눈으로 보여줍니다.
- 시작 화면에서 난이도와 문제 수를 고를 수 있게 하고, 랜덤 생성으로 무한히 놀 수 있게 합니다.
- 화면 버튼은 `pointerdown` 하나만 씁니다. `onmousedown` 과 `ontouchstart` 를 같이 쓰면 터치 기기에서 두 번 눌립니다.
- 키보드 입력은 `if (e.repeat) return;` 으로 길게 누르기를 막습니다.

## 해설위원 사진 넣기 (소싸움 대회)

`games` 폴더에 **`caster.png`** 파일을 넣으면, 소싸움 게임의 해설위원이
도트 캐릭터 대신 그 사진으로 바뀝니다.
(`caster.jpg`, `caster.jpeg`, `caster.webp` 도 됩니다.)

- 사진은 세로로 살짝 긴 비율(3:4 정도)이 가장 잘 맞습니다.
- 도트 느낌을 살리려고 일부러 거칠게 확대해서 보여줍니다.
- 파일을 넣지 않으면 지금처럼 도트 캐릭터가 나옵니다.
- 해설위원 이름은 `games/bull.html` 위쪽의
  `const CASTER_NAME = '황소 아저씨';` 한 줄을 고치면 바뀝니다.

## 해설 음성 넣기 (소싸움 대회)

소싸움에서 소가 부딪히는 소리와 관중 함성은 코드로 만들어 나옵니다.
해설 **목소리**는 두 가지 방식 중 하나로 나옵니다.

1. **직접 녹음한 파일** — `games/voice` 폴더에 mp3 를 넣으면 그 소리가 나옵니다.
   파일 이름 규칙은 `games/voice/README.txt` 에 적어 두었습니다.
   (예: 맞혔을 때 `right1.mp3`, 틀렸을 때 `wrong1.mp3`)
2. **파일이 없으면** 브라우저가 한국어로 직접 읽어 줍니다.
   따로 설정할 것은 없습니다.

경기 화면 오른쪽 위 🗣 버튼으로 음성을 끄고 켤 수 있습니다.
