🔧 게임 추가하기

새로 만든 게임 코드를 붙여넣고 버튼만 누르면, 놀이터에 자동으로 올라가요. ← 놀이터로 돌아가기

1. 깃허브 연결 연결 안 됨

한 번만 입력하면 이 브라우저에 저장돼요. 토큰은 깃허브 → Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 이 저장소의 Contents: Read and write 권한으로 만들면 돼요.

⚠️ 토큰은 이 컴퓨터 브라우저에만 저장돼요(다른 사람에게 전송되지 않아요). 아이가 쓰는 태블릿에서는 토큰을 저장하지 마세요. 게임을 올리는 건 어른 컴퓨터에서만 하면 됩니다.

2. 게임 정보

놀이터 첫 화면 카드에 보이는 내용이에요.

3. 게임 코드 붙여넣기

HTML 전체(<!DOCTYPE html> 부터)를 그대로 붙여넣으세요. 「🏠 놀이터로」 돌아가기 버튼은 자동으로 넣어 드려요.

4. 진행 상황

아직 시작하지 않았어요.

5. 놀이터에 있는 게임

목록에서 빼면 첫 화면에서 사라져요(파일은 저장소에 그대로 남아요).
