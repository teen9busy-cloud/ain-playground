소싸움 해설 음성 파일 넣는 곳
=================================

이 폴더(games/voice)에 mp3 파일을 넣으면,
소싸움 게임에서 그 소리가 해설 음성으로 나옵니다.

파일 이름은 아래 그대로 지어 주세요.

  맞혔을 때        right1.mp3  right2.mp3  right3.mp3  right4.mp3  right5.mp3
  회심의 일격      crit1.mp3   crit2.mp3   crit3.mp3
  틀렸을 때        wrong1.mp3  wrong2.mp3  wrong3.mp3  wrong4.mp3  wrong5.mp3
  잘 버텼을 때     tank1.mp3   tank2.mp3
  경기 시작        start1.mp3  start2.mp3
  이겼을 때        win1.mp3    win2.mp3
  졌을 때          lose1.mp3   lose2.mp3

- 다 넣을 필요 없습니다. right1.mp3 하나만 넣어도 그것부터 나옵니다.
- 같은 종류 파일이 여러 개면 그때그때 하나를 골라 나옵니다.
- 파일이 없는 종류는 브라우저가 한국어로 직접 읽어 줍니다.
- 한 마디는 2~3초를 넘지 않는 게 좋습니다.
- 휴대폰 녹음기로 직접 외쳐서 녹음하신 걸 넣으면 제일 좋습니다.
  (m4a 로 녹음되면 mp3 로 바꿔서 넣어 주세요)

경기 화면 오른쪽 위 🗣 버튼으로 음성을 끄고 켤 수 있습니다.
